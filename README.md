# api_yamdb

## Описание проекта

Проект Yatube -

В сервисе реализовано:

- регистрация пользователя
- авторизация по JWT
- CRUD операции постов
- подписка на авторов, получение всех подписок
- коментирование постов

## Используемые технологии

- JWT авторизация
- django REST framework
- python
- sqlite

## Установка

- `python -m venv venv` (создание виртуального окружения)
- `source venv/Scripts/acticate` (активация виртуального окружения)
- `pip install -r requirements.txt` (установка зависимостей)
- `cd /api_yamdb` (переходим в проект)
- `python manage.py runserver` (запуск сервера)

## Документация

После запуска `runserver`, можно перейти в [документацию](http://localhost:8000/redoc)
